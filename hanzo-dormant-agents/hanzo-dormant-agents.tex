\begin{abstract}
An agent platform is usually costed as though an agent were a process. It is the
natural reading of the deployment shape --- one container per agent --- and it
sets the per-agent floor at the container runtime's minimum reservation, which
on commodity platforms is 128--512\,MB\@. At that floor a fleet of a million
agents is a datacenter, and every design decision downstream of the estimate is
made in its shadow.

We take the estimate apart. An idle agent is three separable things: the
\emph{state} it will resume from, the \emph{execution context} that holds its
loop, and the \emph{isolation boundary} its code runs behind. These have no
reason to cost the same, and measured on one laptop they differ by five orders
of magnitude. State at rest is a row: \textbf{\rFleetPer{}\,bytes} on disk
\meas{}, so \rFleetAgents{} dormant agents occupy \textbf{\rFleetDisk{}\,MiB}
--- written at \rFleetRate{}\,agents/s and resumed in
\textbf{\rFleetResume{}\,ms} in-process. Execution at rest is a goroutine:
\textbf{\rGoPer{}\,bytes} of heap \meas{}, identical on every run, so a million
live loops are \rGoHeap{}\,MB and each starts in \rGoSpawn{}\,ns. Isolation is
the expensive one, and it is expensive for a reason: an in-process V8 context
costs \rVeight{}\,ms \meas{} but runs only JavaScript, while an OCI container
costs \rOci{}\,ms --- \rOciRatio{}$\times$ more --- and is the only one of the
two that can run a test suite, a package manager or a shell.

The conclusion is not that containers are wasteful. It is that a fleet pays for
isolation \emph{per running agent}, not per registered one, while the industry
estimate charges the isolation price to every agent in the fleet whether or not
it is doing anything. Separating the three costs makes the dormant majority
nearly free: \rFleetAgents{} dormant agents are \rFleetStorage{} dollars a month
of storage \modeled{} beside a control plane that costs \$\rPlaneCost{}
\cited{}. We give the capacity model this implies, and we are explicit in
\S\ref{sec:limits} about what \rGoPer{}\,bytes is: a floor for an agent holding
nothing, not a forecast for an agent holding a conversation.
\end{abstract}
