\section{Evaluation}
\label{sec:evaluation}

\paragraph{Backends.}
\textbf{Kai}: revision \res{kj/kai/model} on the native runtime
(\res{kj/kai/device}, \res{kj/kai/dtype}), run by \texttt{bench}.
\textbf{Laya}: Laya 0.3.20's own Python reference runtime on its published
weights, CPU f32, each case on the checkpoint Laya's router picks; the router
sends typed-decision states to the English checkpoint, so Laya-TD, the
typed-decisions checkpoint Laya ships, is reported beside it.
\textbf{Jev}: \res{kj/jev/model} through OpenRouter, served as
\res{kj/jev/served}. All three answer identical questions.

\paragraph{Scoring.}
The frozen harness's functions, upstream's metric code verbatim, score every
backend; an unanswered question is counted, never scored wrong. Accuracy is
top-1; Brier sums over options; ECE uses 15 bins of top-label confidence; AURC
is the area under the risk--coverage curve; \emph{zero-p} is the share of
answers giving the gold option probability below $10^{-6}$, an error no
confidence threshold catches. \texttt{scripts/results.py} reads the artifacts
\texttt{data/runs.json} names and writes \texttt{results-data.tex}; each cell
below is a key into it, and a key no run has written prints \ph. Numbers in
this section are \meas{} unless marked.

\subsection{Capabilities existing decision models lack}
\label{sec:capabilities}

These suites are built by \texttt{hanzoai/benchmarks}
\texttt{decision/capability} in the harness's case format and scored by its
functions; every backend gets the same cases, and Laya is Laya's reference
runtime.

\paragraph{Cardinality.}
One choice among $K$ options: $K$ = 4, 16 and 77 from Banking77 (at 4 and 16
the gold label with its nearest labels by word overlap), 150 from CLINC150, and
1{,}000 to 100{,}000 from WordNet, a definition to be matched to its concept
among co-hyponyms and filler. Accuracy counts an unanswered question as wrong.
Laya fits all options in one sequence and \emph{rejects} a question whose
option markers fall past its context; its authors' recipe for many options,
a top-20 shortlist from Laya's own encoder, is reported as \emph{shortlist},
a gold label outside the shortlist being a miss. Jev's refusals count as
rejected.

\paragraph{Joint coherence.}

typed questions on one state (a vehicle's fault, severity, readiness, action
and review; a source selection's option, evidence, risk, readiness and
review), with gold computed from a latent world by a policy the state spells
out, so every gold answer satisfies every rule. The baselines answer each
question independently. \emph{Acc.}\ is per-variable accuracy, \emph{exact}
the share of states with all five right, \emph{violations} the share whose
answers break a rule; \emph{projected} applies the same exact projection to
every backend's marginals. Kai runs the schedule of
Section~\ref{sec:diffusion} (\texttt{bench refine}) at one to three passes.

\paragraph{Invariance.}
\emph{Permutation}: 200 Banking77 questions of 16 options, each asked in five
orders; \emph{flip} is the share whose top answer changes in any order,
\emph{TV} the mean total variation from the first order, \emph{max} the largest
probability change seen, the test of a claim of exact invariance.
\emph{Swap}: 400 \op{noul} questions asked as is and with the two sides'
descriptions exchanged; \emph{mirror} is the share whose answer mirrors,
\emph{gap} the mean $\lvert p'_{\op{true}} - (1 - p_{\op{true}})\rvert$.
\emph{Labels}: the permutation cases with labels in snake case and as opaque
codes carrying the text as description; \emph{flip} against the labels as
written. Proposition~\ref{prop:symmetry} predicts zero flips and gaps for Kai
up to rounding.

\paragraph{Media, refresh, conformal sets, deployment.}
\emph{Media}: decisions whose evidence is a time series with its metadata,
audio, an image or video; Kai reads the records through its encoders, Laya
and Jev text renderings of them. \emph{Refresh}: a study program is run, one
evidence record changes, and it is run again; \emph{asked} counts the questions
the second run puts to a model, \emph{full} those a fresh run puts.
\emph{Conformal}: split-conformal sets~\cite{vovk2005} at a 90\% target;
coverage and mean set size. These suites are specified and not yet built, so
Table~\ref{tab:media} prints \ph. Deployment needs no suite: Kai and Laya run
offline on the caller's hardware, send no state off the host and charge no
per-call fee \shipped; Jev needs the network, sends each state to OpenRouter,
and cost \$\res{kj/jev/costk} per 1{,}000 calls on the harness
(\$\res{kj/jev/cost} over \res{kj/jev/calls} calls).

\subsection{Speed}
\label{sec:speed}

A call is one state with $N$ questions, from tokenising to probabilities on
the host. States are the harness's typed-decision states in turn, questions its
distinct question definitions in order, wrapping; at each $N$ the first call is
discarded and the next are timed one at a time, percentiles nearest-rank.
Kai runs natively (\texttt{bench speed}); Laya runs Laya's reference runtime
in Python, every question its own sequence in one forward pass, on the
typed-decisions checkpoint; Jev is one Decisions API call, split into the
largest chunks it accepts, eight in flight, when it refuses the whole. All run
from one Apple M1 Max.
