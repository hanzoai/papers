\begin{abstract}
Modern autonomous agent architectures spend substantial computational budgets on discrete, bounded decision problems: selecting among candidate tools, routing queries across service taxonomies, evaluating code diffs, and triaging execution failures. Standard industry practice delegates these discrete choices to autoregressive large language models (LLMs) via prompted token generation, which couples bounded classification to sequential token decoding and prompt formatting.

We describe \textbf{Kai}, a specialized decision model engineered to evaluate structured, typed decision spaces over operational evidence, and \textbf{Hanzo Decision}, the deterministic policy plane that governs it. Rather than synthesizing free-form text, Kai emits calibrated probability distributions over typed candidate sets (\texttt{choice}, \texttt{noul} boolean, and ordinal \texttt{score}). Because candidate options are scored independently by a factorized cross-attention head and normalized jointly, option scoring is invariant to candidate ordering by construction. On the frozen 12-suite decision harness (\texttt{hanzoai/benchmarks} at commit \texttt{2c74e2d}), \texttt{kai-1} achieves a mean accuracy of $0.857$ against $0.780$ for \texttt{typesafe/jev-1.13-20260917} (outperforming Jev on 11 of 12 suites) and a mean Expected Calibration Error (ECE) of $0.093$ versus $0.139$. We further detail how learned consequence predictions from Kai compose with \textbf{Nio}, a deterministic policy verifier that enforces provenance checks and confidence floors ($\tau \ge 0.90$) without altering raw model predictions.
\end{abstract}

\section{Introduction}

Autonomous systems and multi-agent workflows execute iterative sense-decide-act loops. While open-ended text synthesis is critical for drafting prose or generating code, many intermediate operational steps represent bounded, discrete decision problems:
\begin{itemize}
    \item \textit{Tool Dispatch}: Selecting a capability from a catalog of schema definitions.
    \item \textit{Intent Routing}: Classifying customer queries or workflow tickets into service destinations.
    \item \textit{Safety Guardrails}: Evaluating operational states before deterministic policy gates permit or escalate actions.
    \item \textit{Execution Triage}: Determining whether an integration test failure requires retrying, patching, or human escalation.
\end{itemize}

Prompting an autoregressive LLM to resolve these problems presents four structural limitations:
\begin{enumerate}
    \item \textbf{Sequential Decoding Overhead}: Autoregressive token decoding requires sequential generation steps even when the valid output space is a known finite set.
    \item \textbf{Prompt Order Sensitivity}: Concatenating candidate options into a single causal prompt makes attention weights dependent on the linear order in which options appear.
    \item \textbf{Misaligned Calibration}: Next-token probabilities over subword vocabularies do not directly yield calibrated categorical distributions over domain options.
    \item \textbf{Syntactic Fragility}: Relying on regex or JSON parsers to extract structured outputs from generated prose introduces schema drift and parsing errors.
\end{enumerate}

Kai separates bounded judgment from open-ended generation. Under this paradigm, generative engines (such as Zen) synthesize language and reasoning trajectories, Kai produces probability distributions over bounded decision variables, and deterministic policy retains final authority.

Kai is exposed via the Hanzo Decision interface specified in HIP-1332:
\begin{center}
\texttt{POST https://api.hanzo.ai/v1/decisions}
\end{center}

\subsection{Typed Question Primitives}

A decision request evaluates an operational \textit{state} against one or more typed questions:
\begin{itemize}
    \item \textbf{Choice} (\texttt{choice}): Multi-way categorical selection over a candidate set. Kai outputs a probability distribution across all valid candidates.
    \item \textbf{Noul} (\texttt{noul}): Two-sided boolean decision evaluating affirmative versus negative propositions.
    \item \textbf{Score} (\texttt{score}): Ordinal evaluation across an ordered set of discrete criteria levels, trained with the ranked probability score (RPS).
\end{itemize}

\subsection{Factorized Option Scoring}

Prompt-based LLMs process candidate options in linear order within a single sequence. In contrast, Kai encodes the question and state as one sequence and encodes each candidate option independently ($\texttt{[CLS] option [SEP]}$, up to 512 tokens) through a shared 22-layer, 768-dimensional multilingual encoder (mmBERT-base), followed by two cross-attention blocks and a scalar scorer. For candidate sets exceeding 160 options, a 256-dimensional dual-encoder retrieval stage shortlists the top 160 candidates before cross-attention scoring. Because each scored option is evaluated independently against the encoded state and normalized via a symmetric softmax, reordering the candidate map commutes with normalization:
\begin{equation}
\mathcal{P}(\pi(C) \mid S) = \pi(\mathcal{P}(C \mid S)) \quad \forall \, \pi \in \mathcal{S}_K
\end{equation}
where $C$ denotes a candidate set of size $K \le 160$, $S$ denotes the input state, and $\mathcal{S}_K$ is the symmetric group of permutations.

\section{Separation of Learned Judgment and Deterministic Policy}

A core architectural principle of Hanzo Decision (HIP-1332) is that a learned decision model is never an autonomous authority. We strictly separate:
\begin{enumerate}
    \item \textbf{Kai (Learned Decision Model)}: Produces unmodified, temperature-calibrated probability distributions over candidate choices, entity spans, entity kinds, and consequence counts directly from neural model weights.
    \item \textbf{Nio (Deterministic Policy Layer)}: An independent, rule-governed verification engine (e.g., \texttt{nio/harm@2}) that inspects Kai's probability distributions alongside verifiable text provenance.
\end{enumerate}

Under \texttt{nio/harm@2}, categorical consequence predictions cannot authorize an action unless: (a) the learned model's calibrated confidence on every required grounding variable meets or exceeds the policy floor ($\tau \ge 0.90$), (b) the cited evidence substring is verbatim-verified within the input state, and (c) deterministic numeral and safety-invariant checks detect no unquantified human risk or contradictory framing. Whenever any condition fails, Nio deterministically escalates rather than guessing.

\subsection{Production Latency Context}
On production CPU infrastructure serving \texttt{POST /v1/decisions}, a single \texttt{noul} (yes/no) decision executes in $38\,\text{ms}$ at p50, while a batch of 100 independent questions in a single request completes in $13.9\,\text{s}$. Complex multi-question causal grounding requests evaluated under multi-worker load exhibit higher latency ($2.5\text{--}3.3\,\text{s}$ p50 on CPU when scoring multiple entity, count, kind, and certainty heads per request).

\section{Conclusion}

Discrete decisions represent a distinct computational primitive from open-ended text generation. By combining a factorized cross-attention decision reader (Kai) with a deterministic, provenance-verifying policy layer (Nio), Hanzo Decision provides typed, calibrated probability distributions and auditable safety gates at \texttt{POST /v1/decisions}.
