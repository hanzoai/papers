\caption{Enso serving architecture. \textbf{(a)}~\texttt{enso} turns a request
into a feature vector $x$, scores every arm profile $p$ by the learned bilinear
utility $x^{\top}Wp$, and returns the SLO-feasible $\arg\max$ of
$u-\lambda c-\mu\ell$: exactly one frontier arm is selected per request. A
two-tier safety guard gates the request, and each served outcome feeds an
\texttt{observe}$(u,x,p,r)$ update that adapts the per-user weights $\theta_u$
online (LinUCB). The routing policy and the closed learning loop are the ones
specified in the Hanzo Router paper~\cite{hanzorouterpaper}. \textbf{(b)}~\texttt{enso-ultra}
reuses the same learned policy to select the top-$N$ arms, dispatches them in
parallel, and fuses their candidate answers with a training-free synthesizer.
Orchestration is training-free; all learning lives at the routing layer.}
\label{fig:arch}
